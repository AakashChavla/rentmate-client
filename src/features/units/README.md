# Units and occupancy

The feature exposes a thin /units route, grouped floor/wing grid, status icons and labels, filters and cursor loading. Injected UnitsApi adapters use the generated OpenAPI contract. Decimal rent remains a string through forms and HTTP calls. Mutation actions use property-scoped permissions; the server remains authoritative.

Unit drawers provide editing, validated configuration, amenities and PG bed management. Bulk creation previews the server's deterministic codes, validates pattern limits and polls scoped asynchronous jobs. Status changes use expectedStatus and restore the prior query snapshot and selection on failure. Occupancy widgets show accessible totals/progress and lazy-load Recharts; AnimatedNumber animates counters. English/Hindi catalogs, reduced motion and form/accessibility tests accompany the feature.
